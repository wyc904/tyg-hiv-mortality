# 变量字典（按脚本用法整理）

> 本字典由脚本中的变量名与计算逻辑推断，**不是**原始数据库的正式数据字典。正式定义、单位与编码请以论文方法学、CRF 或原始数据说明为准。

## 1. 结局与随访

| 变量 | 含义 / 用法 | 备注 |
|---|---|---|
| `d28` | 28 天随访时间，用于 `Surv(d28, D28)` | 主分析的生存时间 |
| `D28` | 28 天死亡事件（0/1） | 主分析的结局指示变量 |
| `hoslos` | 住院时长 | 旧脚本/敏感性分析使用；部分 Cox 曾与 `住院死亡` 搭配 |
| `死亡` | 住院死亡（0/1） | 旧口径，与 `D28` 不同 |
| `28天死亡` | 28 天死亡（0/1） | 细胞因子/热图脚本中的列名 |
| `year1_los` | 1 年随访时间 | 2024 MIMIC 练习分支 |
| `year1_outcome` | 1 年结局 | 2024 MIMIC 练习分支 |

> `d28`（时间）与 `D28`（事件）大小写不同，含义不同；混用会导致 `Surv()` 报错或结果错误。

## 2. TyG 指数与分组

| 变量 | 含义 / 计算 | 备注 |
|---|---|---|
| `tg` | 甘油三酯（mg/dL） | 原始变量 |
| `glu` | 空腹血糖（mg/dL） | 原始变量 |
| `TyG_index` | `log((tg * glu) / 2)` | 主暴露；脚本未做单位换算 |
| `TyG` | TyG 二分位分组（0/1） | 多数脚本按 0/1 使用；切点约 9.22 |
| `TyG2` | 二分位分组（0/1），由 `1-计算tyg.R` 生成 | 本轮由原第二个 `TyG3` 改名而来 |
| `TyG3` | 三分位分组（1/2/3） | `1-计算tyg.R` 前段生成；`2-四分位间距.R` 也生成 |
| `TyG34` | 四分位分组（1–4） | `1-计算tyg.R` 生成 |
| `TyGbmi` | TyG-BMI 复合指标 | 脚本直接使用，未见计算过程；推测为 TyG × BMI，需以原始数据为准 |
| `TyGbmi3` | TyGbmi 三分位（1/2/3） | 旧分析使用 |
| `TyGbmi4` | TyGbmi 四分位（1–4） | 切点应基于 `TyGbmi`（本轮已修正） |
| `TYGCD4` | TyG 与 CD4 的联合四分组（1–4） | 主分析的分组变量 |
| `MI_2.0` | `(TyG^2)/log10(CD4+50) + 3*TyG*(CD4<50)*(TyG>9.0)` | 自定义复合指标，权重需方法学说明 |

## 3. 免疫与疾病严重度

| 变量 | 含义 / 用法 | 备注 |
|---|---|---|
| `CD4` | CD4 分层（0/1，<50 vs ≥50） | 在 `5-1-COX模型.R` 中作为因子，参考组为 1 |
| `CD41` | CD4 的另一种编码/连续值 | 与 `CD4` 并存，使用前需确认编码 |
| `CD4_score` | CD4 评分（1/2/3：<50 / 50–199 / ≥200） | `12-分层数据.R` |
| `HIVRNA` | HIV RNA 载量 | 原始变量 |
| `HIVRNA_score` | HIV RNA 评分（1–4） | `12-分层数据.R` |
| `ThTs` | Th/Ts 比值 | 原始变量 |
| `ThTs_score` | Th/Ts 评分（1/2/3） | `12-分层数据.R` |
| `sofa` / `SOFA` | SOFA 评分 | 不同脚本大小写不一致，使用前核对 |
| `GCS` | 格拉斯哥昏迷评分 | 原始变量 |
| `GCS_sofa` | GCS 对应的 SOFA 评分（0–4） | `12-分层数据.R` |
| `呼吸指数` | 氧合/呼吸指数 | 原始变量 |
| `呼吸_score` | 呼吸指数评分（0–4） | `12-分层数据.R` |
| `循环` | 循环系统评分 | 原始变量 |
| `PLT` / `Cr` / `TBIL` | 血小板 / 肌酐 / 总胆红素 | 原始实验室指标 |
| `PLT_score` / `Cr_score` / `bilirubin_score` | 器官障碍分项评分（0–4） | `12-分层数据.R` |
| `器官障碍11` | 6 个器官障碍分项中 ≥2 分的个数 | `12-分层数据.R` |

## 5. 细胞因子

| 变量 | 含义 |
|---|---|
| `C0`–`C7` | 标准曲线浓度点，用于 `approx()` 插值 |
| 细胞因子列 | 12–13 项细胞因子；具体列名以 `细胞因子1300初步数据1.xlsx` 为准 |
| `standardized` / 标准化列 | `1-细胞因子标准化.R` 生成的标准化浓度 |

> 标准化使用 `approx()` 线性插值，`rule = 2` 会把超范围值压到端点（截断外推），方法学部分需说明。
